朋友们，先问你一个问题，你手机上的 Obsidian 是不是有成千上万篇笔记了，我估计应该吃灰已久了吗，有价值吗，有，但是怎么体现价值呢，不知道，因为缺乏工具。所以就没法把这么海量的笔记的价值发挥出来。

![[01_raw/_inbox/文章/images/93480fb6f6ece60cfcb191f3ceb94a43_MD5.png]]

所以呢，[前天我们刚发布了 Obsidian CC 的移动版 Mobie CC，错过的朋友可以翻上一篇](https://mp.weixin.qq.com/s?__biz=MzkxNzY0OTA4Mg==&mid=2247494204&idx=1&sn=cd9f156ad037cae8d51bff8d317ac237&scene=21#wechat_redirect)。发布之后我自己拿它当主力用了几天，把上面这些问题挨个撞了一遍，于是这几天几乎没停，一路迭代到了 0.3.8。今天这篇把现状一次讲清楚，写给所有重度使用 Obsidian 的朋友。

先划重点，0.3.8 能给你什么：

-   -   **敢跑长任务了**：锁屏、切后台、被系统打断，回来从断点接着跑，做完的步骤不重复执行；
-   -   **有现成的工作流**：公众号写作、每周复盘、知识综合，开箱即用，还能教它新的；
-   -   **它认识你**：六层长期记忆，记得你的目标、文风和项目进度，每一条都经你审核才写入；
-   -   **试用零门槛**：装上就有 24 小时完整试用哦。

### 请允许我用三十秒时间，说清它是个什么东西

Mobie CC 是装在 Obsidian 移动端里的 Agent 插件，一句话说穿了漏水：让你过去写下的笔记，持续参与今天的工作。如图：

![[01_raw/_inbox/文章/images/35138467210fdd32fc030a2a60212fb5_MD5.jpg]]

mobile CC 首页

它不是远程控制你的电脑，也不是把桌面版界面塞进手机，Agent 的编排、工具的执行、笔记的索引全部在这台手机上完成。桌面的 Obsidian CC 已经有 150 多位付费用户，其中大半是往 Vault 里积累了好几年的重度用户，这群人的真实反馈撑起了移动版的产品判断。

上一篇我们讲过它的三个核心入口：从 Vault 找答案、把当前这篇做得更好、把讨论成果写回 Vault。这三个入口现在都在，本文不重复展开。今天要讲的是这几天新增的东西，它们回答的是另一个问题：当真要在手机上干活，会发生什么。

### 手机上跑长任务：被打断，回来接着跑

这一轮迭代我用得最多的一组升级，全跟一件事有关：任务的生命周期。

首发版有一个遵循 Obsidian 插件机制的设计：插件一切到后台，Agent 就主动停下来。当时的考虑是省电和稳妥，但实际用起来才知道有多难受，地铁上让它整理笔记，屏幕一黑任务就没了。

0.3.7 开始我们把这个逻辑整个删掉，只要系统还允许 Obsidian 运行，任务就尽力继续。你锁屏、切出去回消息，回来时它大概率还在往前走。

更进一步的是断点机制。Agent 每跑一轮、每调用一次工具，前后都会存一份检查点。就算系统真的把进程杀了，重新打开后它也能认出上次跑到哪一步，从断点继续，而不是从头再来。已经完成的那些步骤，结果会直接复用，不会替你再花一遍钱。

![[01_raw/_inbox/文章/images/dcb89218e13e9cf34f71ff1a49587221_MD5.png]]

请注意，这个地方是交互上会在对话中出现一个按钮，点一下继续刚才终端的任务

所以，再长对话也不怕了。一轮讨论聊到几万字，插件会自动把较早的部分压缩成摘要，原始消息原样保留，摘要随时可以撤销。你可以把它理解成一次不限字数的长谈，中间有人帮你翻篇，但草稿永远都在。

### 同时推几件事：多会话、分叉和按任务选模型

重度用户的典型状态是几条线并行。周五晚上你可能既在整理周报，又在琢磨下周的选题，还想把上周没聊完的一个判断继续下去。所以会话是多线程的，新建、切换、重命名、删除，各自独立，互不携带上下文。

这一版还加了分叉。一个讨论走到一半，你想换个方向试试，又不想丢掉已经建立的上下文，直接从当前会话分一个新分支出去，两条线各聊各的。说白了，这就是把 Git 的 branch 搬进了对话里，试探性的想法随便开叉，成了就留着，不成就删掉。

![[01_raw/_inbox/文章/images/017cf305c37f1d8842875e36e36f815d_MD5.jpg]]

有了分支的能力

然后就是，模型这边给了完全的自由度。设置里可以保存多个模型配置，OpenAI 系、Anthropic 系、智谱的兼容接口都行，每个对话单独选用哪个。主模型超时、限流或者服务端报错，插件会自动切到下一个可用配置接着跑；只有认证失败、欠费这类硬错误才会停下来，然后我会把原始报错亮给你看。日常琐事配个便宜的模型，写稿这种大事配强的，各走各的，谁也不耽误谁。

输入框里打个斜杠，还有一排命令可用：`/compact` 手动压缩，`/model` 切模型，`/memory` 看长期记忆，`/private` 进隐私模式。

![[01_raw/_inbox/文章/images/0b0b9036c20f3b381fa49c25378fcfdb_MD5.png]]

内置工作流

### 三个内置工作流，你也可以教它新的

这一版加了我认为对重度用户复利很大的一样东西：Skill 工作流。

内置了三个。公众号协作，围绕选题、结构和表达跟它一起推稿子；每周复盘，把你一周的日记和项目进展拢成一份复盘；知识综合，把散在多篇笔记里的观点整理成待审核的知识候选。三个工作流装好即用，产出全部走候选审核，不会乱写。

你也可以自己定义。工作流就是一个放在插件目录里的 `SKILL.md` 文件，把你的固定流程写成说明，之后一句指令就能唤起。你手里任何重复性的动作，比如每周固定格式的汇报、固定的素材整理套路，都值得沉淀成一个，这是越用越顺的资产。

有一处设计想专门提一下：这一版其实还内置了一个技术文章写作的 Skill，因为我特别需要这个技能，但它是默认关闭的，因为他不是通用的，也许你就用不上，如果用得上，再手动开启。我觉得，克制地给功能比一股脑全塞给你更难做，但我认为这是对的。

![[01_raw/_inbox/文章/images/c669b2c9936cf394187c18b37c7c1ac9_MD5.jpg]]

### 它记得你是谁，但每条记忆都过你的审

Mobie CC 会随着使用越来越懂你。它维护六层长期记忆：你的身份与长期目标、表达偏好、工作方式、Vault 的组织约定、每个长期项目的状态，还有一份按日期滚动的每日日志。

![[01_raw/_inbox/文章/images/1cd4b02ff3cd97fc5c7dac2c38b2d549_MD5.jpg]]

长期记忆管理

比如你不喜欢浮夸的标题，希望文章读起来像跟老朋友聊天；比如你的素材统一放在哪个目录、哪些笔记绝对不许读。这些它会逐渐掌握，并且带进之后的每一次对话。

然后，更加关键的是写入规则这里。Agent 觉得你表达了一个稳定偏好，它不会直接记下来，而是先生成一条记忆候选，你在审核中心看到原文，可以改、可以拒绝，确认后才生效，而且从下一轮才开始用。一次性的要求、敏感的信息、置信度不高的猜测，都进不了长期记忆。

它还能翻旧账。你问它我们上个月是不是讨论过这个问题，它会先检索你们过去的对话记录再回答。设置页里所有记忆都能看、能改、能删，解释权一直在你手里。

### 读图、读 PDF、读网页，但写库必须你点头

输入不再只是文字。图片、PDF、Canvas 白板都可以作为附件加入当前对话，模型能力跟得上就能直接处理。它也能读公开网页，你可以配置禁止访问的域名，内网和本机地址天然不开放。图片和 PDF 的识别效果也取决于你配置的模型，插件自己不做本地 OCR，模型配置弱，多模态体验就会打折扣。

需要外部能力的话，这一版接入了远程 MCP 服务。任何公开的 HTTPS MCP 工具都能挂进来，每个对话单独启用，每次调用都有权限确认，等于给插件留了扩展的口子，将来新的工具生态直接接得上。

![[01_raw/_inbox/文章/images/973c1d78ef344f1555b2d7918f61856e_MD5.png]]

但所有这些读取能力，都换不来一次未经批准的写入。Agent 想往库里写东西，只能先创建知识候选：你先看到它准备写什么、写到哪篇，可以改标题改正文，看 diff，确认后才真正落盘；目标笔记如果没被再次动过，写完还能撤销。再加上不允许读取的目录、允许写入的目录两层范围控制，以及一个把工具全部收走的隐私模式，边界是清晰的。它也不跑 Shell，不碰 Obsidian 之外的任何文件。

底层那套中文检索索引，这几天也重做了一轮。几万篇笔记的手机上可以增量索引，体积有硬上限，索引中途被系统打断也不会陷入闪退循环，下次启动自己重建。这块没什么炫的，但大库用户装上后能直接感受到差别。

### 首发版和 0.3.8，一张表看变化

| 能力 | 首发版（0.2.x） | 现在（0.3.8） |
| :-- | :-- | :-- |
| 长任务 | 切后台即终止 | 断点续跑，已完成结果直接复用 |
| 模型 | 单一配置 | 多配置、每会话选择、故障自动回退 |
| 长对话 | 手动开新会话 | 自动压缩、摘要可撤销、可分叉 |
| 工作流 | 无 | 内置三个，支持自定义 SKILL.md |
| 长期记忆 | 四层 | 六层，新增项目状态与每日日志 |
| 输入 | 文字、网页 | 加上图片、PDF、Canvas |
| 外部扩展 | 无 | 远程 HTTPS MCP |

### 写在最后，如何安装使用

写下的笔记是存量，被用起来的笔记才是资产。Mobie CC 想做的就这一件事：把你 Obsidian 里沉睡的积累，变成每天替你干活的活水。

安装有两种方式。推荐用 BRAT：先在 Obsidian 里装第三方插件 BRAT，添加分发仓库 `bravekingzhang/mobie-cc-releases`，之后就可以自动安装自动更新了，特别方便。

![[01_raw/_inbox/文章/images/1bb966ae9f529734dc74293960fb0299_MD5.jpg]]

通过 Obsidian 的 BRAT 插件安装本插件
